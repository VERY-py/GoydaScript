# GoydaScript

Шуточный язык программирования основанный на Python.
Для запуска любой программы на нём нужен Python 3.11+

Язык пока не доделан и реализованны только методы: сложение, вычитание, if/elif/else, for.
Простой синтаксис, смесь Python и C++

Для запуска запустите runGoyda.bat, затем введите название файла с расширением .goyda (файлы языка), включите/выключите режим отладки.
Пример программы в файле test.goyda
