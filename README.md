# GoydaScript

Шуточный язык программирования основанный на Python.
Для запуска любой программы на нём нужен Python 3.11+.

Язык пока не доделан и реализованны только небольшую часть методов.
Простой синтаксис, похожий на смесь Python и C++

Для запуска компиляции и выполнения откройте консоль в папке с goyda.bat и по очереди выполните команды:
```
set PATH=%PATH%;%CD%
```
```
goyda ваш_файл_кода.gs 
```
Как доп. аргументы можно использовать:
```-dsmall``` - базовая информация отладки
```-dfull``` - полная информация отладки
без доп. аргументов просто выполнения кода

Пример программы в файле test.gs:
```
goyda test.gs
```
